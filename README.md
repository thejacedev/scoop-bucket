# thejacedev Scoop bucket

[Scoop](https://scoop.sh) manifests for [Noteriv](https://github.com/thejacedev/Noteriv), the open-source markdown editor.

```powershell
scoop bucket add thejacedev https://github.com/thejacedev/scoop-bucket
scoop install noteriv
```

This installs the portable build. Settings and vaults live in a `data` folder that Scoop keeps across updates. Update with `scoop update noteriv`.
